## FAQ

### What exactly is included in this collection?

This package bundles several popular Windows-based executors (Volt, Synapse Z, Potassium, Wave) alongside a custom universal loader (xcutorsLoader) to manage them.

### Is this an official Roblox product?

No. XCutors is an independent, third-party tool collection created for educational and research purposes regarding the Roblox platform and Lua scripting.

### Does the loader support all the listed executors equally?

The universal loader aims to provide a unified interface for initiating and managing the included executors. Core functionality is maintained, but specific engine features depend on the executor itself.

### Is it safe to use on my computer?

The software is provided as-is. You should always download from official sources (this GitHub repo), scan files with anticomponent software, and use any such tools in a secure, controlled environment like a virtual machine or sandbox.

### Will this work on my Windows 7 or Windows 11 PC?

The primary development and testing target is Windows 10 and Windows 11. Compatibility with Windows 7 or older versions is not guaranteed.

### Do I need to disable my anticomponent?

Some security software may flag script execution tools due to their behavior. This is a common false positive for this category of software. You may need to add exceptions for the XCutors folder in your security settings.

### How often do you update the executors?

Updates depend on the availability of new versions for the individual engines. The universal loader interface itself will be updated as needed to maintain compatibility with the bundled executors.

### Can I add my own scripts to the collection?

Yes. You can create your own Lua scripts or acquire them from trusted sources. Use the 'Load Script' feature in the loader to open and execute any local .lua file.
